      Security note: this page uses the same lightweight gate as the Cross Country admin — a value in localStorage, checked client-side, with the password written in login.html. Anyone who can read the page source can bypass it. It is fine for a small team, but before you use this for real lists, move the gate and the send behind Firebase Auth or a Cloud Function so the database rules can require an authenticated writer.
